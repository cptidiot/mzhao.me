**X 观点**

- [Thibault Sottiaux（Codex & ChatGPT @ OpenAI）](https://x.com/thsottiaux/status/2116405414921384099)：第 26 天分享：移动端现已可以轻松切换多个账号，桌面端也即将上线；并预告接下来两天会是“重置”主题，留了个悬念。账号切换这类小体验正在被 OpenAI 逐个补齐。
- [Amjad Masad（CEO @ Replit）](https://x.com/amasad/status/2116343923925041462)：如果把应用托管在 Replit 并打开“autofix”，它就变成了自维护软件：出问题能自己修。把 agent 的自主修复从演示变成了默认开箱的能力，运维的人力成本有望再降一档。
- [Amjad Masad（CEO @ Replit）](https://x.com/amasad/status/2116341851825287476)：发布 Replit for Government，把 agent 开发平台推进政府场景。政府客户对合规与安全的要求最高，Replit 敢在这个时候进场，说明它对平台的成熟度有了信心。
- [Garry Tan（President & CEO @ Y Combinator）](https://x.com/garrytan/status/2116303457774899251)：GBrain Cloud 是最快用上 GBrain 的方式：每个 agent harness 各有所长——Grok、Muse、Dots 适合个人，OpenClaw、Hermes 偏重算力，Claude Code、Codex、Capy 擅长写代码——而 GBrain 让你的上下文能在所有这些 agent 上通用。
- [Zara Zhang（Builder）](https://x.com/zarazhangrui/status/2116283023415287932)：一段视频剪辑只用 1 条提示词（很长的一条）就由 coding agent 完成。提示词写得够细，agent 就能一次交付成片，视频制作的门槛正在被长提示词 + agent 组合压低。
- [Zara Zhang（Builder）](https://x.com/zarazhangrui/status/2116281211962454056)：分享视频 essay：不会设计的人如何用 AI 做出有品味的东西。审美不再是设计师的专利，关键在判断力与提示词——这正是非设计背景的 builder 最需要补的一课。
- [Boris Cherny（Claude @ Anthropic）](https://x.com/bcherny/status/2116222842413142111)：宣布正在为已验证的 Ultra 账号取消 5 小时用量上限。这是 Claude 订阅体系松绑的关键一步，重度用户不再被 5 小时窗口卡住，Ultra 的 $200 定价也因此更值。
- [Josh Woodward（VP @ Google）](https://x.com/joshwoodward/status/2116220878593900775)：上周五 iPhone Duo 发售，Gemini App 首日即已针对它优化。AI 应用对新硬件形态的跟进速度越来越快，首发适配本身已成为竞争的一部分。
- [Claude（Claude 官方）](https://x.com/claudeai/status/2116220869479428500)：订阅改名：Max 5x 改为 Max、Max 20x 改为 Ultra，价格不变（$100/$200）；同时为已验证的 Ultra 账号取消 5 小时上限，新账号验证通过前仍有临时上限以防欺诈，周上限不变。老用户无需任何操作。
- [Thariq（前 Claude Code @ Anthropic）](https://x.com/trq212/status/2116212324696777073)：认为几乎所有人都预测不好“更多智能会以什么方式进入经济”；最简单的答案——“花很多钱、让所有人失业”——其实并不够 AGI-pilled，我们应该避免把这种悲观叙事自我实现式地念成现实。
- [Thariq（前 Claude Code @ Anthropic）](https://x.com/trq212/status/2116212322838655014)：对经济悲观主义的解法是更加 AGI-pilled：相信一个能解释自己工作、带着每个人一起前进的对齐良好的 ASI，让每个人都变得最大程度地有效。这是一种主动乐观的立场选择。
- [Amjad Masad（CEO @ Replit）](https://x.com/amasad/status/2116183233784394039)：Replit 写了一份白皮书，讲如何正确地给 agent 做沙箱：既最大化生产力、又降低风险。agent 越来越能动真格的系统，沙箱设计正在从工程细节变成产品战略问题。
- [Peter Steinberger（OpenClaw）](https://x.com/steipete/status/2116153238563242385)：再添一个用自己的 harness 而不是别人平台的理由：别人可以随心所欲改你能做什么、不能做什么。把控制权握在自己手里，是 agent 时代一条朴素但重要的防身原则。
- [Ryo Lu（设计师，前 Cursor、Notion、Stripe）](https://x.com/ryolu_/status/2116126528060973480)：在 iPhone Duo 上跑自己的 ryOS，并称比 iOS 更好。继 Cursor、Notion、Stripe 的设计履历后，他正在把“让任何人都能做软件”的愿景做到新硬件形态上，值得看实机表现是否撑得起这句话。
- [Peter Steinberger（OpenClaw）](https://x.com/steipete/status/2116121832919122164)：看好 Andy Yen 和 Proton。他理解工程师在 AI 重塑工作时感受到的身份失落与文化战争，也理解经营者耐心有限：大家已有两年时间去消化、学习和改变。这是一场关于适应速度的讨论。

**播客**

- [Taking on ServiceNow: Coding Agents the Rest of Us with Serval Co-Founder and CEO Jake Stauch（No Priors）](https://www.youtube.com/@NoPriorsPodcast)：Serval 联合创始人兼 CEO Jake Stauch 谈如何用代码生成 agent 正面挑战 ServiceNow：核心论点是自主 agent 在企业里是“无界的安全风险”，没人能马上放心放行，而 Serval 就是边界与护栏，让规则、审批和流程繁多的大企业能安全地大规模用 agent。他还强调 Serval 从第一天就直攻大型企业而非先做中小市场，因为服务大企业的产品、团队与增长逻辑从根本上不同；agent 不只是代劳，更是能带着用户一起探索的“建造伙伴”，会提升一大批用户的技术能力。
