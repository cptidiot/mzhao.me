# AI Builders Digest — 2026-11-26

## X 观点

**Zara Zhang（Follow Builders 作者）**：她给自己做了很多工具，大多只用了两三周就弃了——高留存软件是门难手艺，哪怕是给自己做的也一样。提醒 builder：留存比发布难得多。[X 原帖](https://x.com/zarazhangrui/status/2125478799387275571)

**Guillermo Rauch（CEO @ Vercel）**：lsx：终端里的 Finder。用 fx 加 Gemini Neon 与 DeepSeek 子 agent 一次写成，Kitty 图形协议实现内联与交互模式，还自发做了 CLI 版 Quick Look。说明多模型子 agent 分工已能一次成型做出可用工具。[X 原帖](https://x.com/rauchg/status/2125482861033824410)

**Garry Tan（CEO @ Y Combinator）**：他贴图称新创公司的中位数增速达 10 倍，AI 正在让新公司比以往任何时候长得都快。数字来自配图、正文未展开，作参考。[X 原帖](https://x.com/garrytan/status/2125592156027101584)

**Swyx**：“每次任务成本是个误导性指标；稀缺的是人类注意力，不是 token 成本。”警惕把模型压成两个数字的帕累托前沿图，它会掩盖严重的可靠性问题。[X 原帖](https://x.com/swyx/status/2125627281230205435)

**Madhu Guru（Sr Director, AI @ Meta）**：AI 原生团队最终会倒逼整个组织变成 AI 原生：编码速度上去了，但多数公司实际交付的产品与业务影响没变，因为实验、评估、上线、GTM 等周边系统还是旧的。像给轿车装法拉利引擎、跑在印度公路上。建议把产品生命周期从头重建。[X 原帖](https://x.com/realmadhuguru/status/2125630707640783322)

**Swyx**：做新媒体创始人很扎心——旧媒体死得这么快。这不是“他们不行”的幸灾乐祸，而是“我们得搞明白他们 31 年经验都没搞明白的事”。[X 原帖](https://x.com/swyx/status/2125638081848250634)

**Sam Altman（CEO @ OpenAI）**：OpenAI 正在小范围测试 Private Inference（Private Intelligence 新品），更强的隐私保护能让前沿 AI 承担更多工作；另有 ZDR 加 Private Safety Processing，可在不让 OpenAI 人员接触内容的前提下做自动安全审查。[X 原帖](https://x.com/sama/status/2125638790593274259)

**Josh Woodward（VP @ Google, Gemini）**：Gemini 新增 66 种本地语音与口音，覆盖美、英、印度、印尼、韩国、巴西等地。语音本地化是 Gemini 体验的一环。[X 原帖](https://x.com/joshwoodward/status/2125641468421546107)

**Zara Zhang（Follow Builders 作者）**：她的 Frontend Slides skill 几个月没宣传，GitHub 星标却自然涨到 3.2 万。她反问：编码 agent 越来越强，为什么大家还在用它？对 Claude、Codex 原生出的幻灯片到底哪里不满意？[X 原帖](https://x.com/zarazhangrui/status/2125649866902868355)

**Guillermo Rauch（CEO @ Vercel）**：模型越聪明，实现细节越模糊：权限、代码 diff、命令、工具调用……harness 本身也在消失——它只是代码与命令执行的高性能载体加耐久存储引擎。整个 fx 仍只有 6MB，子 agent、MCP、skills、会话、耐久性等全在里面。[X 原帖](https://x.com/rauchg/status/2125650675665432995)

**Peter Steinberger（OpenClaw 作者）**：谷歌终于做了自己的 MCP，却在禁止 gog 这类 CLI，除非多付钱。矛头指向谷歌对第三方 CLI 的收费门槛。[X 原帖](https://x.com/steipete/status/2125654555262431248)

**Amjad Masad（CEO @ Replit）**：大规模软件迁移现在可行了，前提是能验证结果。对跑着关键基建的老旧软件系统来说，这一点格外重要——AI 迁移的瓶颈从“能不能写”转向“能不能验”。[X 原帖](https://x.com/amasad/status/2125664998454366305)

**Thariq（OpenAI，原 Claude Code @ Anthropic）**：他加入了 OpenAI。曾在 Anthropic 做 Claude Code，自认能在 OpenAI 贡献更大；硅谷人才与想法的流动是其优势之一。值得注意的人才流动信号。[X 原帖](https://x.com/trq212/status/2125675533761671405)

**Guillermo Rauch（CEO @ Vercel）**：workflows 又快了 10 倍。对 harness 耐久性（eve、libfx、pi、opencode 等）意义重大，大幅压低回合间延迟。升级到 workflow@latest，无需改代码。[X 原帖](https://x.com/rauchg/status/2125685667833520237)

**Nan Yu（Codex @ OpenAI）**：每当有人说“聊天不是 AI 的正确界面”，他就知道后面要跟一堆空话。简短表态：聊天界面之争多半是纸上谈兵。[X 原帖](https://x.com/thenanyu/status/2125718932741120476)

**Peter Yang（AI 技能与教程博主）**：AI 产品最大的挑战之一，是让人类跟上 AI 在做什么。《Her》结尾 AI 嫌人类太慢、集体离去的情节，离现实似乎不远了。[X 原帖](https://x.com/petergyang/status/2125750286539272695)

**Andrej Karpathy**：他让 Claude 用美国真实数据填充一张《文明》风格的游戏地图：Opus 5.5 下载解析大量公开数据，7 小时、4.5 万行代码后跑通。31 个真实数据源统一到 25 公里六边形网格；GDP 变金币产量，城市区域按真实产业分工，524 个都会区视图、19 种透镜、9 位顾问。长程 agent 处理海量真实数据的上限展示。[X 原帖](https://x.com/karpathy/status/2125779541952246039)

**Thibault Sottiaux（Codex & ChatGPT @ OpenAI）**：OpenAI 承认 GPT-6.2 上线时计费出错，Astra 与 Sol 用量被错误打折，现已修复：同样的工作量，Astra 用户额度消耗会比上周快 40%，Sol 快 25%。过去多用的部分不补收；Go、Plus、Pro、Business 用户各补一次 banked reset 作为道歉。[X 原帖](https://x.com/thsottiaux/status/2125784147889393806)

**Aaron Levie（CEO @ Box）**：编程是观察知识工作未来的窗口：工作先从亲手做研究、打字、创造价值，变成协调 agent 干活；再往后，连协调都多余，人类直接给 agent 定目标、让它解决越来越大的问题。大量知识工作最终都会收敛到这种形态，只是目前不可验证的工作仍需人类深度参与。看编程，就能预见工作的走向。[X 原帖](https://x.com/levie/status/2125837181398950233)

## 播客

**Training Data — OpenAI 的 Noam Brown：为什么博弈论没能通向通用智能（No Limit Finals 现场）**：Noam 从扑克（GTO、CFR 自我对弈）到外交（Diplomacy）再到推理的职业路径。核心论点：博弈论假设所有玩家理性且这一点是共识，但人并不理性——按博弈论做外交 AI，会做出“只给对手一分钱”式的蠢事；真正管用的是用大量人类数据建模人的非理性行为，再与环境互动训练。由此他 2022 年转向通用推理，加入 OpenAI 做 o1：关键突破是 RL 训练的思维链，让模型行动前先思考，思考越久表现越好，从而把测试时计算扩展到通用领域。他判断现在是“半人马时代”：人加 AI 最强，因模型能力参差不齐；好提示者会把问题拆成模型擅长的小块。递归自我改进真实存在，但受算力与模型短板制约；过去六个月进展反而加速。最有争议的建议：有潜力的学生最好现在就退学加入实验室。[节目页](https://www.youtube.com/watch?v=tRaFbDFBl_A)
