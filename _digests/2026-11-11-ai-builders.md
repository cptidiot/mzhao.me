## X 观点

**Josh Woodward（VP @ Google）**：Gemini 4 Carbon 现已向全球 Ultra 订阅用户开放，入口在 Gemini App 内。这是 Google 新一代模型首次大规模进入付费用户手中，从发布进入真实使用的检验阶段。[X 原帖](https://x.com/joshwoodward/status/2120186249281778135)

**Dan Shipper（CEO @ Every）**：Every 团队首日实测 Gemini 4 Carbon：高级工程师基准上 Carbon 得 44%，Argon 只有 21%；它能连续工作数小时，写了内部视频编辑器 Everycut 一次大更新约 95% 的代码，还能从会议录音里剪出 6 条短视频。但它不知道何时停手——曾把 6 个待办做成 15 个、干了近 4.5 小时。写作与 Argon 差不多、价格却更高，他的结论是“偶尔用用”。[X 原帖](https://x.com/danshipper/status/2120187507396530309)

**Aaron Levie（CEO @ Box）**：Agent swarm（智能体群）可能带来 AI 产出的又一次跃升：聊天只是让回应更快，单个 agent 能把几小时的工作压缩到几分钟，而成群的目标导向 agent 会自行找到完成项目的路径，生产力没有天然上限。采用这种工作方式的团队与不采用的团队之间会出现清晰分化；搭建 agent 运行的脚手架与应用基础设施将是一片新机会。[X 原帖](https://x.com/levie/status/2120385739342897469)

**Aaron Levie（CEO @ Box）**：Box 与 Anthropic 合作，Claude 通过 MCP 获得对 Box 内容的完整读写互通：agent 不只可以调取文件，还能直接把合同、演示文稿、战略文档的修改写回 Box，并在 Claude 内查看。未来 agent 处理企业文件的工作量将是人的 100 倍，平台要让 agent 与人的协作无缝且安全。[X 原帖](https://x.com/levie/status/2120261416733036905)

**Guillermo Rauch（CEO @ Vercel）**：Vercel Security Review 上线不到一周：已发现 57,897 个漏洞，其中 6,029 个为严重或高危，agent 已自动修复 14,665 个。他惊讶于两点：大量严重漏洞平时无人察觉，以及 agent 自动修复的容易程度。该功能可为任何仓库开启，不论部署在哪里。[X 原帖](https://x.com/rauchg/status/2120188488628977819)

**Guillermo Rauch（CEO @ Vercel）**：Rust 是极好的语言与生态，尤其考虑到它诞生于 agent 编程时代之前。有了 agent，新的语言会大量涌现，甚至是为特定场景量身打造的语言，乃至直接写 C、LLVM IR 或汇编。AI 是流动的，不再有一刀切的方案。[X 原帖](https://x.com/rauchg/status/2120337388178379178)

**Claude**：Claude Data（原 Dashboards）今日起在付费计划上全面上线：除仪表盘外，Claude 还能根据指标起草数据故事与解说视频供审核后分享，认证查询与实时分享在测试中。同时推出交互式连接器：可在 Claude 内直接打开 Adobe、Atlassian、Box 等工具的完整版本，自己改或让 Claude 帮你改；Whiteboards 与 Sheets 也在陆续推出。[X 原帖](https://x.com/claudeai/status/2120206372478566799)

**Thariq（前 Claude Code @ Anthropic）**：我们需要更少的一次性演示、更多展示如何与模型协作、把愿景变成现实的工具。一次成型的炫技固然好看，但真正有价值的是人机协作的过程——这也是 builder 该投入的方向。[X 原帖](https://x.com/trq212/status/2120223476279869875)

**Ryo Lu（前 Cursor、Notion、Stripe 设计师）**：魔法发生在人与人一起工作的时候，而不是每个人各自指挥一支 agent 大军、在孤岛里运转。他为这种协作的回归感到高兴——对 builder 的提醒是：agent 时代更要设计好人与人之间的协作。[X 原帖](https://x.com/ryolu_/status/2120337691661443081)

**Zara Zhang**：用户不回来的原因，20% 是不喜欢你的产品，80% 是根本忘了你的产品存在。留存问题的核心往往不是产品差，而是缺乏提醒与触达——值得 builder 优先补上召回环节。[X 原帖](https://x.com/zarazhangrui/status/2120235104194932841)

**Zara Zhang**：分享作品、建立受众的第一步：别等做完或完美了再分享，分享进行中的作品。有时正是在分享的过程中，你才弄清这件事值不值得做完。[X 原帖](https://x.com/zarazhangrui/status/2120041030951297033)

**Peter Yang**：他不太在意股价，但如果 Anthropic 能加速治愈这些可怕的疾病，将成为历史上最有影响力的公司之一。他很高兴 Dario 把精力放在这件事上，而不是去争病毒短视频与 TikTok 梗。[X 原帖](https://x.com/petergyang/status/2120320377163501817)

**Peter Yang**：赞同 Kartik 的观点：游戏开发者与玩家仇视“有品味地”使用 AI 是愚蠢的。用 AI 批量生产粗制滥造的内容，和把它当作做好游戏的另一种工具，完全是两回事。[X 原帖](https://x.com/petergyang/status/2120370522622181809)

**Swyx**：他终于问了 Resend 创始人 Zeno Rocha：为什么他的 agent 明明没被要求用 Resend，却总选 Resend。答案指向 AEO（agent 时代的搜索引擎优化）——agent 如何挑选工具，正在成为新的获客战场，相关讨论也见本期播客。[X 原帖](https://x.com/swyx/status/2120260228902264872)

## 播客

**Latent Space × Zeno Rocha（Resend 创始人）**：主题是“为 agent 设计产品”。Resend 如今服务 430 万用户、12 万付费客户、年经常性收入约 1000 万美元，下载量今年初超过 SendGrid、如今已是其两倍多。Rocha 认为 agent 选 Resend 的关键不是传统 SEO：模型对新工具有“时效偏好”，加上大量真实用户内容让它被反复推荐；他的做法是把定价等关键信息用纯文本写在页面上（JS 控件模型读不到）、另设专门的 AI 页面讲集成。MCP 使用量每月翻倍，8 月底达到 120 万；第一个 MCP 还是 a16z 投资人做的开源版，要做远程 MCP 倒逼团队重做了 OAuth 与权限模型。展望上，他正在为 agent 批量创建收件箱做准备：agent 读邮件、发邮件将成为基础设施的一部分。[节目页](https://www.youtube.com/@LatentSpacePod)
