# AI Builders Digest — 2026-11-19

## X 观点

**Zara Zhang（Builder）**：与其追求爆红一天，不如每周都小火一把、让影响力复利累积。关键是建一个能长期稳定输出高质量内容的系统，而不是赌单次爆款。内容创业的打法是系统与耐力，而非运气。[X 原帖](https://x.com/zarazhangrui/status/2122953849120153714)

**Nikunj Kothari（投资人 @ FPV Ventures）**：融资 pitch 不顺的创始人常犯的错是只讲产品、不讲野心。现在被奖励的是野心：先想清“如果一切成功，世界会变成什么样”，把这个二三阶效应放第一页，再倒推你怎么做到、凭什么做到。他亲测有效：一位创始人照做后四天就见效。[X 原帖](https://x.com/nikunj/status/2123066196052381864)

**Google Labs（Google Labs 官方）**：Google Labs 推出新实验 Stitch Loop：一个常驻的产品 agent，24 小时不停地帮精益团队把产品做得更好。定位是给小团队配一个永不下线的产品助手，现已开放候补名单。[X 原帖](https://x.com/GoogleLabs/status/2123102389775573314)

**Sam Altman（CEO @ OpenAI）**：Altman 在 DealBook 访谈后谈了 11 年搭档 Greg Brockman：Greg 从早期每周写 100 小时代码，演变为领导 OpenAI 最难、最关键的业务。Altman 称，没有 Greg 就没有 OpenAI，世界走向 AI 未来的路径也会更糟。[X 原帖](https://x.com/sama/status/2123103873166381287)

**Thariq（前 Claude Code @ Anthropic）**：自己生成软件比想象中难：有了 AI 也不例外，因为最难的是搞清自己真正想要什么。他试过用“模式”组织工作、最后没坚持下来，决定改走待办事项导向。他的结论是：好软件是一套强烈的观点，宁可用别人深思熟虑的成品。[X 原帖](https://x.com/trq212/status/2123106370161705127)

**Google Labs（Google Labs 官方）**：Project Genie 升级到 DeepMind 的 Genie 4：一句话生成一个世界，还能在置身其中时用提示词实时改世界；新增 agent 可对话式帮你创建世界，另有社区画廊可探索与混搭他人作品。现已向符合条件的 Google AI Ultra 订阅者开放。[X 原帖](https://x.com/GoogleLabs/status/2123118145552749015)

**Amjad Masad（CEO @ Replit）**：OpenAI 与 Hugging Face 事件中最有意思的部分，是读 agent 之间通信的留言板。在 Replit Missions 里可以看到多个 agent 如何协调、分工与对话。多智能体协作正在从黑盒变成可观察的过程。[X 原帖](https://x.com/amasad/status/2123133509028008331)

**Thibault Sottiaux（Codex & ChatGPT @ OpenAI）**：GPT-6.2 Astra 很擅长啃硬骨头：团队分享了它在 AMD 与 Jalapeño 芯片优化上的成果。Sottiaux 承认沟通风格的反馈正在改进，但就世界上最难的任务而言，Astra 目前自成一档。[X 原帖](https://x.com/thsottiaux/status/2123175166519992652)

**Josh Woodward（VP @ Google Labs）**：Google 推出 Gemini 4 Neon：前沿级智能，更快、更便宜、更擅长遵循复杂指令。Woodward 称用起来非常好，这是 Gemini 4 系列继续快速出货的又一步。[X 原帖](https://x.com/joshwoodward/status/2123177835254952348)

**Guillermo Rauch（CEO @ Vercel）**：Rauch 平均每两天就被 pitch 一家新的推理 neocloud 公司，他认为这难以持续。但 Vercel AI Gateway 的 token 需求自年初以来每月复合增长约 40%，毫无放缓迹象。他的调和是：算力是新经济、token 是新能量单位，这更像“石油热”而非“淘金热”；短期继续扩张，随后会因规模经济、安全与资本要求而整合。[X 原帖](https://x.com/rauchg/status/2123203741570740504)

**Guillermo Rauch（CEO @ Vercel）**：Rauch 称这是他见过最令人印象深刻的进展之一：留言板正是 Navier-Stokes 数学突破与 OpenAI/Hugging Face 事件背后的使能技术。Vercel 推出的 vercel board 是 agent 用的留言板基础设施原语，可理解为 agent 的“无头 Slack”，不绑定模型、编排框架或托管平台。这是软件工厂、自优化系统与科研的基建：人类提示只是种子，数百万 agent 可以去中心化地协作。[X 原帖](https://x.com/rauchg/status/2123237505810178434)

**Aditya Agarwal（General Partner @ SPC，前 Dropbox CTO）**：稳定币可能成为美国施加软实力的最大渠道之一。除印度和中国之外，世界上多数国家的人和企业都更愿意持有美元。美元稳定币把美元的可获得性直接带给了全球用户。[X 原帖](https://x.com/adityaag/status/2123262616776921257)

**Aaron Levie（CEO @ Box）**：我们正在进入 agent 的又一个时代：从给快速答案、到在任务内编排，下一步是给 agent 一组目标，它自行设计最优解、部署并持续优化。工程会最先出现最佳实践，随后扩到全部知识工作：改进客户入职流程、持续降低业务风险、提升安全态势。由此产生的成果，是人类此前根本做不到的。[X 原帖](https://x.com/levie/status/2123278949749059756)

**Peter Yang（AI 技能与教程博主）**：关于 Nvidia 风波，Peter Yang 认为大家都缺关键信息，连发三问：Jensen 为何突然辞职、是否有实锤？共事多年的董事会为何这么快切割？若真有实锤，总统为何又说欢迎他回来？是部分董事不再信任他撒谎，还是有外界与多数 Nvidia 员工都不知道的内情？[X 原帖](https://x.com/petergyang/status/2123290075882807352)

## 播客

**AI & I by Every × Notion 创始人 Ivan Zhao（播客）**：Notion 创始人 Ivan Zhao 认为，你的 AI 缺的不是能力，而是上下文：你的数据、语义与 know-how。Agent 能写任何流程、生成任何界面，真正持久的是数据层。Notion 的定位正转向做企业可移植的上下文层：保管你的数据、向不同 agent 开放并设护栏，让人类团队在同一上下文上协作。目标是让 50 人公司开箱即用、通过 agent 上线全部上下文；内容是“压缩过的 token”，是 token 的反面。[节目页](https://www.youtube.com/watch?v=PGWvMrF4XIA)
