# AI Builders Digest — 2026-11-09

## X 观点

**Aaron Levie（CEO @ Box）**：Levie 说 AI 正在从"来回聊天、产出速度跟人对话速度绑定"的时代，转向"给一群 agent 派活、让它们并行干任意规模工作"的时代——生产力提升从 20–50% 变成没有上限。Agent swarm 已在编程领域验证，网络安全、科学、生命科学将是下一批受益者；关键变量从时间变成了算力。[X 原帖](https://x.com/levie/status/2119592025440092192)

**Aaron Levie（CEO @ Box）**：Levie 提醒每 3–6 个月回头试一次之前做不到的事：过去半年模型在电脑与工具使用、上下文保持、推理、多模态和领域专业度上大进，agent 能直接调用现有系统（有 API 的、甚至很多没 API 的也能），不再只靠模型从头生成；不懂 agent 的旧工具会被 agent 友好或开源的工具替代。[X 原帖](https://x.com/levie/status/2119502716770902234)

**Guillermo Rauch（CEO @ Vercel）**：Rauch 用 WebGL2 + Web Audio 做了黑胶唱机的物理仿真：把歌曲转成沟槽的物理形状，模拟唱针每秒 38.4 万次划过沟壁、感应出电压；爆音、噼啪声、抖晃、内圈发闷都是仿真的自然产物，还能"DJ"。歌曲均为公有领域或 CC 授权，代码已开源可 remix。[X 原帖](https://x.com/rauchg/status/2119536313712230802)

**Nan Yu（Product, Codex @ OpenAI）**：Nan Yu 说选架构要选"最笨"而非"最简单"的：简单是迭代出来的，笨才是正确的起点，否则会把自己聪明过头；而且聪明的架构也要求用户同样聪明才能理解。[X 原帖](https://x.com/thenanyu/status/2119462979179892925)

**Nan Yu（Product, Codex @ OpenAI）**：Nan Yu 说软件变容易还是变难，取决于你知不知道自己要造什么：目标清晰就能直达解法；目标模糊只会造出一堆垃圾还烧掉很多钱——AI 时代之前是造不出东西，现在是造出垃圾更快。[X 原帖](https://x.com/thenanyu/status/2119462224721002560)

**Garry Tan（President & CEO @ Y Combinator）**：Garry Tan 的 gstack-evals 项目复现了 Jevons Engineering 那篇文章的结论，复现成立；顺手试了 particle-1，效果甚至更好。Evals 正在变成可验证、可复现的工程实践。[X 原帖](https://x.com/garrytan/status/2119624260675350605)

**Garry Tan（President & CEO @ Y Combinator）**：Garry Tan 说一旦意识到前沿模型改软件如此容易，那些小 bug 就变得难以忍受；与此同时，个人专属的即时软件（just-in-time software）注定会到来。[X 原帖](https://x.com/garrytan/status/2119612084220842483)

**Zara Zhang**：Zara 说她几乎不再用"vibe coding"这个词：它自带负面含义，暗示没投入心力、产出只是 AI 垃圾；但很多人用 AI 编程工具时同样投入了心血，两者并不矛盾——需要一个更好的词来描述这种做法。[X 原帖](https://x.com/zarazhangrui/status/2119592080318341128)

**Zara Zhang**：Zara 说做产品的乐趣，来自技术行为的可预测性与人类行为的不可预测性之间的碰撞。[X 原帖](https://x.com/zarazhangrui/status/2119342420412510686)

**Peter Yang**：Peter Yang 转述 OpenAI 产品副总裁 Ashley Yuki：父母一周内双双确诊两种癌症后，她决定休假一个月照顾父母，称这是当时能做的最好的事；并提醒照护者也要照顾自己——认知、情绪与时间负担都很重，心理健康需要留出预算。[X 原帖](https://x.com/petergyang/status/2119595860057288967)

**Nikunj Kothari（Partner @ FPV Ventures）**：Nikunj 说来旧金山想认识更多人，先从词汇表里删掉"swap notes""synergies""pick your brain""networking""San Fran""有空喝杯咖啡"；最有意思的人不在大型会议上，而在办公室里做事——拿出你的作品，一封有想法的冷邮件、五行有针对性的私信、一个做出来的 side project 都算数。[X 原帖](https://x.com/nikunj/status/2119670529254981756)

## 播客

**Latent Space × Mihail Eric（斯坦福 CS 146S《现代软件开发者》讲师、Monaco AI 负责人）**：斯坦福 CS 146S 第二年改版：去年是 coding agent 在软件开发生命周期各环节的"巡游"，今年沉淀为几条原则——大规模上下文工程、为复杂任务做设计与架构、agent-ready 代码库。第一周学生从零写一个约 200 行的 harness，再用 MITM 代理拆解真实 Claude Code 的系统提示与压缩提示。他还把野心门槛抬高：照片转应用已不算有野心，写浏览器才算；第 11 周的"免费建议"是做 benchmark 和 evals——这是进顶级 frontier lab 的敲门砖，SWE-bench 当年就是本科生项目。[节目页](https://www.youtube.com/watch?v=dpY7YzZo4kE)
