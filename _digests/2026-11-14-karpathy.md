**HackerTube**（2026-10-31）[原文](https://karpathy.bearblog.dev/hacker-tube/)

**核心论点**

- 周五深夜 11 点，他累了，想上 YouTube 看点东西，却看到一堵"enshittified wall of slop"——夸张缩略图、翻来覆去的陈旧话题推荐、idiocracy 级别的烂内容。算法对互联网上的中位数用户也许好用，但对他不管用。
- 于是周六早上，他把任务交给 Opus 5.5：基于 Hacker News 上被推荐过的视频，写一个自己的 YouTube 克隆。结果就是 hackertube.org。

**怎么做到的**

- Opus 下载了全部 Hacker News 评论，过滤后用 Sonnet 在 Claude Code 的 Workflow 功能里跑了一遍，去掉 spam，最后筛出 4 万条推荐了 YouTube 视频的评论。
- 汇总得到 6,454 个视频，时间跨度 2007–2026，覆盖 150 个话题，都是曾被 HN 上几个人推荐过的。
- 再套上 YouTube 风格的 UI、买域名、推上 VPS、加固、优化，就成了。

**HackerTube 有什么不一样**

- 内容质量优先：来源是 HN 社区的推荐，而非点击率算法；
- 用视频 50% 处的截图当缩略图，而不是上传者做的夸张封面；
- 有定制且好用的 ForYou 推荐，但不需要用户账号，状态存在本地浏览器 session 里；
- 支持键盘快捷键；
- 可以导出全站数据，交给自己的 agent 就能复刻一个同款。

**更值得注意的是他的工作方式（EDIT 补充）**

- 他用 Mac 上的 Claude Code 桌面 app，默认 Opus 5.5、Medium effort。他说自己已经不再做传统意义上的工程（读写代码、在终端跑命令等），只跟 Claude 对话、让它去做一切。
- 这次他唯一的手动工作只有三件：1）在 Google Cloud UI 里建一个 API key，用来查询 YouTube 视频元数据；2）启动一台 VPS；3）买域名。VPS 上线后，他把 IP 告诉 Claude，让它去更新、部署、加固、优化，全程都是 Claude 完成的——中间穿插着 Claude 干活的间隙，他感觉这仍然有点像团队合作。
- 现在复刻一个 HackerTube 大约只要 2 小时。他最后写道："I can breathe again. Thank you Opus 5.5 <3."

**Takeaway**

- 这篇和他之前写 MenuGen、Sequoia 谈话里的 Software 3.0 主张是同一条线：当 agent 足够强时，"做一个产品"可以从写代码变成一句话的委派，人的工作变成提需求、给资源、验收结果。
- 推荐系统也可以换个思路：不靠中心化算法猜你喜欢什么，而是靠一个高质量社区多年积累的推荐做内容池——对小众品味的人，这种策展可能比为中位数优化的算法好得多。
- 也可以反过来想：如果你对某个平台的推荐算法不满意，现在动手做一个自己的替代品，成本已经低到一个周六早上、几小时、一个 agent 就够了。
