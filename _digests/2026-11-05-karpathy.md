  - title: "Power to the people: How LLMs flip the script on technology diffusion"
    role: "Andrej Karpathy"
    summary: |
      **核心论点**

      - 变革性技术历来是自上而下扩散：先是政府/军方，再到企业，最后才到个人——电力、密码学、计算机、飞行、互联网、GPS 都是如此，因为早期技术稀缺、昂贵、需要专业知识。
      - LLM 彻底反转了这个模式：受益最大的是普通人，企业和政府的收益反而滞后、 muted。ChatGPT 是史上增长最快的消费级应用，每周活跃用户 4 亿；它不是小升级，而是全方位放大个人能力的倍增器，而且门槛极低——免费、快速、随开随用、说任何人的母语。

      **为什么个人受益更多**

      - LLM 的能力画像很特殊：横跨极广领域的"准专家"水平，但同时浅薄、会出错。组织的超能力本就是把各领域专家集中起来，所以 LLM 只能让专家们各自高效一点——组织做的事还是原来能做的事，只是好一点。
      - 个人通常只精通一件事，LLM 的广谱准专业能力让他们第一次能做以前做不了的事：vibe coding 做应用、读法律文件、啃晦涩论文、做数据分析、生成品牌营销的多模态内容——都不用再请专家。

      **为什么组织跟不上**

      - 组织的问题复杂得多、协调成本高得多：各种集成、遗留系统、品牌规范、安全协议、隐私、国际化、合规与法律风险，变量多、约束多、容错率低——"一次灾难性幻觉就可能让你丢掉工作"，没法随便 vibe coding。
      - 再加上组织惯性：文化、历史包袱、地盘之争、沟通开销、再培训难题和官僚主义。

      **展望：这种均等会持续吗？**

      - 关键看性能随资本投入的动态范围。今天前沿模型性能便宜又易得——花再多钱也买不到更好的 ChatGPT，Bill Gates 用的 GPT-4o 和你一样。训练时 scaling、测试时 scaling、模型集成都在拉大这个范围，而蒸馏（distillation）则在缩小它。
      - 一旦钱能买到明显更好的模型，格局就会变：大组织能集中资源买更多智能，个人内部也会分化——"别人家的孩子由 GPT-8-pro-max-high 辅导，你的孩子用 GPT-6 mini"。

      **Takeaway**

      - 这是技术史上前所未有的一刻：AI 革命本该是将军们手里的绝密政府超级大脑，结果却是 ChatGPT 一夜之间免费出现在每个人口袋里的设备上。借用 William Gibson 的话改写："未来已经来了，而且它被惊人地均匀分配了。"Power to the people。
