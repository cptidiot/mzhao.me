**X 观点**

- [Garry Tan（President & CEO @ Y Combinator）](https://x.com/garrytan/status/2118951284376285508)：YC 总裁 Garry Tan 称赞 Aside 的 computer use「非常出色」，关键是它跑在真实 Chromium 浏览器里，几乎没有网站能屏蔽它。这对做浏览器 agent 的人是个信号：真实浏览器环境仍是绕过反爬、跑通复杂站点的硬通货，agent 的执行层正在向「真浏览器」收敛。
- [Garry Tan（President & CEO @ Y Combinator）](https://x.com/garrytan/status/2118950671886287323)：Garry Tan 转述一项研究：仅用 300 万 token、取自普通人面对复杂道德困境的建议，就把模型的恶意行为降到 0%，且跨代效率提升 28 倍。数据来自原帖引用的研究，他未展开方法细节——若属实，意味着对齐不一定靠海量标注，普通人的道德直觉本身可能是高性价比的训练信号。
- [Zara Zhang（Builder）](https://x.com/zarazhangrui/status/2118939184841052386)：Zara 再次强调：个人网站就是新的简历。LinkedIn 只列一串头衔，个人网站才能展现品味、思考和真实作品；不必被现有社交平台框住。对 builder 而言，这是把作品、观点和长期积累沉淀到自己地盘上的提醒，而不是只活在别人的时间线里。
- [Garry Tan（President & CEO @ Y Combinator）](https://x.com/garrytan/status/2118920030243139596)：Garry Tan 认为 agent skill 的开发必须走评估驱动的循环：每个新模型都更强，不再需要的东西就该删掉。他刚删掉了 /investigate 这个 skill，因为 Opus 5.5 不用它做得更好。「能感受到 AGI 的浪潮在上涨」——skill 不是越堆越多，而是随模型能力进化不断瘦身。
- [Swyx（AI Engineer，Latent Space）](https://x.com/swyx/status/2118905788915982341)：Swyx 宣布将每周跟进 Anthropic IPO，直到它上市或不上市为止。他曾以股权对冲基金分析师身份覆盖过阿里巴巴到 Atlassian 等大型 IPO，这次将与好友 Jamin Ball 合写，后者正挑战 Tunguz 成为这一代「作家型 VC」。Anthropic 若上市，将是 AI 实验室资本化的标志性事件。
- [Guillermo Rauch（CEO @ Vercel）](https://x.com/rauchg/status/2118856239719608353)：Vercel CEO Guillermo Rauch 认为生成式 UI 将成为对话式 agent 的主导人机交互范式：把 AI SDK 与 Chat SDK、json-render 结合，可以直接从 LLM 输出生成 Slack、Teams 等平台上的界面。他相信这会成为主流——agent 不再只回文字，而是直接长出可操作的界面。
- [Nikunj Kothari（Partner @ FPV Ventures）](https://x.com/nikunj/status/2118840414853861627)：Nikunj Kothari 重新介绍了 texts wrapped：一条终端命令即可分析 iMessage、WhatsApp 与通话记录，跑在 Mac 本地、100% 本地、无 AI、开源，新版换了界面、洞察更准。对想复盘自己沟通模式的人，这是个不用把聊天记录交给云端就能用的工具。
- [Thariq（前 Claude Code @ Anthropic）](https://x.com/trq212/status/2118822238262853904)：前 Anthropic Claude Code 成员 Thariq 注意到一个模式：Instagram Edits、Roblox Studio 这类创作者应用开始内置 MCP，让 agent 直接在应用里干活，而重度用户仍能在熟悉的工具里接手协作。他喜欢这种分工：agent 做执行，人做把关，创作工具正在变成人机协作的界面。
- [Peter Yang（AI 教程与访谈博主）](https://x.com/petergyang/status/2118811231545122998)：Peter Yang 观察到：能调用多家实验室模型的独立应用（如 Conductor、Cursor）正被实验室逐个收购，剩下的多是开源项目（t3、Orca）。他认为用户与企业对「跨实验室模型」的应用仍有大量需求，问题在于这层需求最终由谁来满足——独立应用的生存空间正在收窄。
- [Nikunj Kothari（Partner @ FPV Ventures）](https://x.com/nikunj/status/2118758688567792008)：Nikunj Kothari 用讽刺长帖拆解了一套「两周内把公司做到 1 亿美元」的剧本：200 万美元 pre-seed 里 40 万拍启动视频、50 万买 token，靠 LOI 与 cARR 包装收入，再以 FOMO 流程把估值从 4000 万一路炒到 1 亿。他注明这是讽刺，但「每一句话都真实发生在我身上」。

**播客**

- [Controlling Biology - Fabian Theis, Helmholtz Munich（Latent Space）](https://www.youtube.com/@LatentSpacePod)：Latent Space 访谈 Helmholtz Munich 的 Fabian Theis，聊虚拟细胞与 AI for Science。核心是三段演进：从绘制人类细胞图谱，到预测扰动，再到操控实验——他的团队刚推出 Lab Compass（逆向生成模型），能反推「要达到某个细胞状态该做什么实验」，终极愿景是把实验循环 RL 化。他也坦言领域曾被线性基线「泼冷水」：Arc 的虚拟细胞挑战赛证明简单模型在不少任务上不输基础模型，真正的进步要靠更难的任务与可验证的 scaling law；其 3.5 亿细胞、16 物种的模型已显现规模效应。商业化上，纯平台难变现，护城河在「模型 + 独有数据」，如与药企共建的癌症类器官扰动图谱。
