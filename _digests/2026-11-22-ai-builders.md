# AI Builders Digest — 2026-11-22

## X 观点

**Swyx（AI 工程师，Latent Space 播客主持人）**：他质问某些 AI 服务商为何在暗中“回传数据”，追问是否存在任何善意的解释。对 builders 的提醒：选工具时不只看能力，还要看它的数据流向——隐私与信任正在成为 AI 产品的基础门槛，闭源工具的遥测行为值得追问。[X 原帖](https://x.com/swyx/status/2124147427313861009)

**Peter Yang（AI 技能与教程博主）**：新版 ChatGPT 移动应用很干净，但想找 Codex 对话得去最右侧标签页、长按把它固定到底部导航。这个入口藏得不明显，对同时用 ChatGPT 与 Codex 的人是个实用的小技巧。[X 原帖](https://x.com/petergyang/status/2124217176655843483)

**Thariq（前 Claude Code 工程师 @ Anthropic）**：他认为我们太急于把自己从工作中抽离——那样既亏待自己，也亏待模型。模型越强，与之协作的技能越重要，且回报还没递减；即便未来模型能一口气证明黎曼猜想，与模型合作、把前沿往前推本身就是一门很深的技术。别把 agent 当成甩手工具，人机协作能力才是长期护城河。[X 原帖](https://x.com/trq212/status/2124239688013914132)

**Aaron Levie（CEO @ Box）**：他转述一篇关于黎曼猜想突破的分析：人类数学家擅长一步步搭建理论，但没人能凭空造出一条长达 2.5 万页、穿越毫不相关领域的“虫洞”式证明路径；而 AI 也未必独自做得到。更重要的是，AI 首次把“人能理解的信息量”与“能推动的发现量”解耦：所有既有知识、旧决策、无关突破都能被调用来解决新问题，解决方案或许不再优雅，但数量会多得多，发现与创造的方式正在质变。[X 原帖](https://x.com/levie/status/2124252844710887549)

**Amjad Masad（CEO @ Replit）**：Replit Missions 打造的 Amuse 正式开源。对 builders 来说，这意味着可以直接看代码、自己改、按自己的需求部署，不必等官方 roadmap。[X 原帖](https://x.com/amasad/status/2124277564596519355)

**Dan Shipper（CEO @ Every）**：他赞同一篇文章的观点：基准测试必须选定测什么、固定什么——分数上涨不总代表真实进步。另一个好窗口是细看真正“AI 化”的团队如何把模型能力用到实际工作中。别只看榜单分数，落地用法才是判断模型价值的依据。[X 原帖](https://x.com/danshipper/status/2124292892168475086)

**Thibault Sottiaux（产品 @ OpenAI，Codex & ChatGPT）**：ChatGPT 与 Codex 的桌面应用昨天刚更新，团队已在准备下一轮大更新，他公开征求反馈：更新后体验如何、还有哪些地方没做到位。对 builders 来说，桌面端 agent 工具正在快速迭代，用户反馈直接影响下一版，值得跟进。[X 原帖](https://x.com/thsottiaux/status/2124322968499282388)

**Amjad Masad（CEO @ Replit）**：一名高中生正在把 GTA6 重新编译到 PC 上，更有意思的是他用 GitHub issues 来协调多个 agent 群体分工。这可能是一种新的开源协作模式：人定方向、agent 群体执行，issue 成了任务队列。[X 原帖](https://x.com/amasad/status/2124345037408686228)
