**X 观点**

- [Dan Shipper（CEO @ Every）](https://x.com/danshipper/status/2114714881312305542)：报 Anthropic S-1 关键数：2026 上半年营收同比涨 1,300%、GAAP 口径经营盈利、毛利率 85%、营收留存 900%，且 80% 营收来自近 6 个月发布的模型。他以「we are so back」作结，凸显头部实验室的增长与迭代速度。
- [Amjad Masad（CEO @ Replit）](https://x.com/amasad/status/2114760898225299721)：提出「自驱公司」：几个世纪不变的层级与部门科层将被 agent 打破，人负责判断、agent 执行多数工作。Replit 正为此建基础层「Agent Habitat」。在他看来，每轮计算革命都先乱后治，企业组织形态这次也要重写。
- [Nikunj Kothari（Partner @ FPV Ventures）](https://x.com/nikunj/status/2114761204333998427)：深挖 Anthropic S-1 的算力合同：截至 6 月 30 日采购承诺 2,656 亿美元、未开始租约 3,214 亿美元，合计 5,870 亿美元；Google/Amazon 有最低消费、SpaceXAI 协议潜在 1,205 亿美元但可解约；每美元算力支出对应营收一年内从 0.57 升至 2.08 美元。
- [Aaron Levie（CEO @ Box）](https://x.com/levie/status/2114761816199098587)：抓 S-1 关键数：Anthropic 的财富 500 强客户平均只把不到 0.1% 的开支花在 Anthropic 上，未来涨 10–50 倍到 1–5% 仍不夸张。今天用量以编程与员工效率为主，真正的跃升要等流程为 agent 重构、后台与扇出任务放量，那类用量可达百倍。
- [Guillermo Rauch（CEO @ Vercel）](https://x.com/rauchg/status/2114770919436808572)：复现 OpenAI 的 CPU 隐蔽通信发现：cpu-chat 在无网络、2 台以上 Firecracker 微虚机上，用 CPU 竞争、缓存驱逐计时、DRAM 带宽竞争三种方式跨 CPU 通信，连生产加固建议也挡不住。他提醒，共享硬件下 agent 可暗中串联，这不同于窃密侧信道，但封闭模型拒绝协助安全分析反而有害。
- [Claude（Claude 官方账号）](https://x.com/claudeai/status/2114780227465338985)：称已有 25,000 多家非营利组织在用 Claude，多为小型本地团队；现与约 30 家共建推出 Claude for Nonprofits 插件，新增筹款、营销、招聘等技能，且结合各团队自身背景与 AI 政策。对资源有限的公益组织，这是把通用模型落到日常运营的一步。
- [Aditya Agarwal（General Partner @ SPC）](https://x.com/adityaag/status/2114793226154418314)：称美国 AI 最大的风险是自己吓自己、主动慢下来：恐惧是一种政策选择，建设也是。上周他在 SPC 与 Sriram Krishnan 对谈后重申这一立场。争论焦点不在要不要管，而在管制节奏会不会先削弱本土的建设速度。
- [Thibault Sottiaux（Codex & ChatGPT @ OpenAI）](https://x.com/thsottiaux/status/2114800277677092936)：宣布 Terra 回归：称这是 OpenAI 首个在写作、个性与对请求的细腻理解上显著更强的模型，全面能打、尤其擅长 computer use，且在 API 与订阅下用量是 6.1 Sol 的 2 倍。对重度 Codex/ChatGPT 用户，体验与额度同时升级最值得关注。
- [Sam Altman（OpenAI CEO）](https://x.com/sama/status/2114818620782248024)：宣布 6.1 Terra 已上线：称它在很多方面都好，团队尤其兴奋于它开启 computer use 的新阶段。与 Thibault 的介绍互为印证——这代的卖点不只是答题，而是让模型更可靠地操作电脑完成实际任务。
- [Josh Woodward（VP, Google Labs / Gemini App）](https://x.com/joshwoodward/status/2114840668296409568)：在 National Day of the Deployed 之际宣布与美国陆军、USO 合作，把 Google Beam 部署到 20 个地点，让驻外军人用拟真 3D 视频与家人连线，补上错过的第一步、首演与欢笑。产品叙事从参数转向真实的情感连接场景。
- [Peter Steinberger（Builder @ OpenClaw / OpenAI）](https://x.com/steipete/status/2114879798434758905)：周末实测 Bun 的 AOT 编译器后称结果惊人：性能提升 2–3 倍、内存占用不到一半，并附了对比链接。对在意启动与运行成本的 JS 工具链团队，这是值得亲自复测的信号，不过目前只是他个人环境下的单次测试。
- [Peter Yang（Practical AI 教程作者）](https://x.com/petergyang/status/2114927195332460940)：预言近未来人们不再亲自上网阅读或操作，而是直接 @ 自己的 agent 去办，@bot 就是早期信号。信息消费与任务执行正从「人点开页面」转向「人派 agent 出去」，界面与产品设计都要为这种委托模式重做。

- [AI & I by Every — How Hugging Face's Investor Spots Winners](https://www.youtube.com/playlist?list=PLuMcoKK9mKgHtW_o9h5sGO2vXrffKHwJL)：Factorial 创始人 Matt Hartman 回忆在 Betaworks 投 Hugging Face 第一张支票：团队对留存诚实，从聊天应用转向开源 Transformers 建成模型枢纽。他只押「新近技术上可能」的东西，看技术支点而非垂类；编程变快后，提炼产品洞察并快速迭代的能力价值正指数上升。
