# AI Builders Digest — 2026-11-17

## X 观点

**Peter Yang（AI 技能与教程博主）**：转述 Anthropic 的 Nate Parrott 教 Claude 做设计、不出 AI 味的五个方法：先给上下文与参考截图、研究熟悉的 UX 范式、把 Claude 的设计偏见写进 design.md、先画线框再抠细节、一次出 5 版再混搭。原型成本已归零，设计流程本身才是方法论。[X 原帖](https://x.com/petergyang/status/2122347721298510021)

**Aditya Agarwal（General Partner @ South Park Commons）**：领投印度半导体公司 BharatSemi 的 2400 万美元种子轮，理由是 AI 要尽可能贴近硅片，而印度也能造芯片。硬科技加印度制造的组合，对关注 AI 硬件链的 builders 是个值得留意的信号。[X 原帖](https://x.com/adityaag/status/2122386958101959118)

**Guillermo Rauch（CEO @ Vercel）**：旧范式是用户访谈、画用户旅程；新范式是用户变成 agent，靠 evals 驱动开发循环，并分享了 Vercel 内部做 evals 的方法。Agent 时代的产品方法论正从“访谈驱动”转向“评估驱动”。[X 原帖](https://x.com/rauchg/status/2122415506451841215)

**Thariq（前 Claude Code @ Anthropic）**：软件工厂只是个过渡问题，模型迟早会自己搭工厂；更有意思的问题是怎么做一个 agent 能与人协作的工作空间。点出了 agent 工具的下一个战场：协作界面，而非生成代码本身。[X 原帖](https://x.com/trq212/status/2122438326431154210)

**Josh Woodward（VP @ Google Labs）**：NotebookLM 能把资料源变成可交互网站，他们用元素周期表做了示例：易做、易分享。知识库秒变可交互产品的思路，对做内容与教育类产品的 builders 可直接借鉴。[X 原帖](https://x.com/joshwoodward/status/2122453269842886788)

**Guillermo Rauch（CEO @ Vercel）**：拥有自己的智能路线图：用开放 SDK 与 harness、经网关自选模型、自己掌控 traces 与数据并强制零留存、私有推理自有模型。给不想被单一厂商锁定的 builders 一张可直接照做的清单。[X 原帖](https://x.com/rauchg/status/2122458782294847807)

**Google Labs（Google Labs 官方账号）**：欢迎 Howie 团队加入 Google Labs：他们多年钻研日程与日历管理，Google Labs 将借此为小企业打造下一代直觉化 AI 工具。日程管理是 AI 助手的高频场景，值得关注后续产品。[X 原帖](https://x.com/GoogleLabs/status/2122461899178820069)

**Peter Steinberger（OpenClaw 创始人）**：大家请苹果减少权限弹窗，好让 agent 在 macOS 上不用人一直盯着；苹果的回应是加了更吓人的新弹窗。Agent 落地桌面的摩擦仍在，macOS 的权限体验仍是瓶颈之一。[X 原帖](https://x.com/steipete/status/2122463466304971068)

**Garry Tan（President & CEO @ Y Combinator）**：真正的无人机自主飞行已可叠加在几乎任何飞行平台上，Degla 已与关键政府机构合作搜救任务。无人机 autonomy 正从演示走向任务级应用。[X 原帖](https://x.com/garrytan/status/2122487869780742304)

**Aaron Levie（CEO @ Box）**：每位员工的 token 花费仍看不到天花板，越靠近 AI 越觉得还在曲线早期：编码 12 个月前还很烂、现在终于能用了，接下来是工具与电脑使用打开的知识工作；agent 群与后台 agent 会消耗远超想象的 token。结论：token 只会继续涨。[X 原帖](https://x.com/levie/status/2122508098351038532)

**Dan Shipper（CEO @ Every）**：设想：AI 时代给 feed 排序的最好方式是工作量证明——让 agent 上报为某条内容花了多少 token，用它来排序。把注意力度量从点击换成算力消耗，是个值得玩味的想法。[X 原帖](https://x.com/danshipper/status/2122541401804054826)

**Nikunj Kothari（投资人）**：2026 基建之战缩影：Q1 vibe coding、Q2 harness、Q3 沙箱、Q4 agentic CI，供应商多到数不过来。帮 builders 一眼看清今年 agent 基建的演进节奏，并追问下一步会是什么。[X 原帖](https://x.com/nikunj/status/2122543500814336281)

**Garry Tan（President & CEO @ Y Combinator）**：未来几周上线的 GBrain 后端引擎用 Rust 写，将替代 postgres+pgvector 或 pglite，支撑向量搜索、图搜索、embedding、RAG 与 HNSW。个人与团队知识库的存储层正在被重写。[X 原帖](https://x.com/garrytan/status/2122576951080792543)
