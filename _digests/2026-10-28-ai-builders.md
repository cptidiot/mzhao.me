**X 观点**

- [Swyx（Latent Space）](https://x.com/swyx/status/2115089887959359988)：自嘲错失机会：SpaceX IPO 时众人晒错过 Cursor 的「bag fumble」，他估自己错失的约达 5 亿美元，并称凭自己 TypeScript CLI 维护者的背景本可能很早加入 Claude Code。数字是他个人估算，价值在于头部 builder 对「想到却没做成」的直白复盘。
- [Dan Shipper（CEO @ Every）](https://x.com/danshipper/status/2115093098816745910)：预言视频创作与游戏制作将像今天的文档与演示一样，成为知识工作的基础技能并广泛普及。生成工具把这两种媒介的门槛拉低后，它们会从专业工种变成人人日常表达与协作的默认形式。
- [Nikunj Kothari（Partner @ FPV Ventures）](https://x.com/nikunj/status/2115111451614744845)：列出一串他自认懂、却仍会被给出 10 种不同定义的 AI 热词——long horizon、out of distribution、intelligence per watt、RL environments、forward deployed、frontier、self improving，提醒行业术语的共识远比表面薄，讨论前先对齐定义。
- [Matt Turck（Partner @ FirstMark Capital）](https://x.com/mattturck/status/2115132327131328806)：用反例挑战「联合创始人太多是坏事」的常规建议：Anthropic 有 7 位、OpenAI 有 11 位、Databricks 有 7 位联合创始人。顶级公司恰是例外样本，说明创始人人数没有普适最优解，不能只用稀释与摩擦风险一概而论。
- [Thariq（前 Claude Code @ Anthropic）](https://x.com/trq212/status/2115135857669881939)：晒个人实验：AI 原生 macOS Dock，可按写作、编程等自定义模式切换以保持专注；他的 agent 能定制模式行为、新增模式，并用 Jev 实时分类他的活动与通知再据此行动。这是把 agent 从聊天框搬进操作系统日常界面的小样机。
- [Thariq（前 Claude Code @ Anthropic）](https://x.com/trq212/status/2115188992861970693)：提出开源软件需要新的分发方式：用户能借 agent 自由修改，同时又能自动合并上游更新。他指出编程 agent 今天能做修改，却不会自动完成这套合并——这是 agent 时代开源维护还没补上的基础设施缺口。
- [Garry Tan（President & CEO @ Y Combinator）](https://x.com/garrytan/status/2115193524152860771)：称 Capy 软件工厂对他 GitHub 贡献图的「再归一化」是真的：他自认原本 token 用量就不低，但现在 PR 又多又密，因为 Capy Captains 让 10–20 个子 agent 在 GStack 与 GBrain 上全时运行。多 agent 并行已把个人产出节奏推到新量级。
- [Amjad Masad（CEO @ Replit）](https://x.com/amasad/status/2115207856496480261)：谈他若投前沿 AI 的下注逻辑：主要押新发现及其在医学等领域的应用，因为编程与多数知识工作正被次前沿模型快速饱和、价值变薄。前沿模型的溢价要靠打开新问题，而非守住已被商品化的任务。
- [Guillermo Rauch（CEO @ Vercel）](https://x.com/rauchg/status/2115218670389756243)：演示 Vercel 部署可以多短：给 vercel 设别名为 now，写一个基于 oven/bun:alpine 的极简 Dockerfile、起一个 Bun 服务，再敲 now 就得到 Ready 链接。卖点是把「写完到上线」压到一条命令，与轻量运行时组合成快速交付样例。
- [Aaron Levie（CEO @ Box）](https://x.com/levie/status/2115305369799110905)：判断企业 agent 实际渗透仍不到 1%：多数流程最多是单次 LLM 决策或反馈，远非真自动化。转折在于 computer use、长时 agent、harness 与基建成熟后，企业会围绕 agent 重构流程、出现自我改进系统与 agent swarm，金融、生命科学、医疗等信息密集行业受影响最大。
- [Peter Yang（Practical AI 教程作者）](https://x.com/petergyang/status/2115319325137731757)：列出该改的招聘陋习：按年限或公司名筛人、重简历文书轻作品与真实项目、把带过多少人本身当成就、用无尽轮次面试替代短期试工。核心主张是把 proof of work 放回招聘中心，这与 AI 时代能快速做出真实产物的趋势直接相关。
