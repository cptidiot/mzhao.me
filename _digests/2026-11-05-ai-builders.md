**X 观点**

- [Swyx（AI Engineer，Latent Space）](https://x.com/swyx/status/2118208851506036989)：Swyx 惊叹 Thinking Machines 的 inkling 模型：蒸馏后速度快 3 倍、成本便宜 5 倍，FrontierCode 2 评测却与原版持平——「无代价的蒸馏」。他认为 inkling 是全球最被低估的基座模型之一，接下来美国预训练模型会涌现大量同类蒸馏版本。对 builder 来说，强模型正在变得又快又便宜，推理成本曲线还在下探。
- [Thibault Sottiaux（Codex & ChatGPT @ OpenAI）](https://x.com/thsottiaux/status/2118146794362405231)：OpenAI 的 Thibault Sottiaux 宣布已组建一支世界级网络安全团队，未来数周、数月将陆续分享工作成果，并公开招募想「保护世界」的人加入。这与昨日 Vercel 的安全 agent 审计呼应：前沿实验室开始把安全能力当作正式产品线来建，而不只是合规点缀。
- [Cat Wu（Core Products @ OpenAI，新任）](https://x.com/_catwu/status/2118137612577968402)：Cat Wu 宣布加入 OpenAI，负责 Core Products 的产品管理。她表示敬佩 OpenAI 证明了 scaling 的可行性、把 AI 带给十亿人，并称接下来要与 Thibault 的团队一起打造「有你后盾、由你掌控」的 agent。Claude Code 前核心成员的流动，也折射出 OpenAI 在核心产品线上的人才吸力。
- [Amjad Masad（CEO @ Replit）](https://x.com/amasad/status/2118180254300688857)：Replit CEO Amjad Masad 宣布与日本三井住友融资租赁（SMFL）合作：Replit 已为其核心软件产品提速——一个项目过去 6 个人干 6 个月，现在 1 个人 1 周完成。双方下一步要把 AI 软件创建带给更多日本企业，帮其应对劳动力短缺。这是 agent 在传统金融巨头落地的又一个可量化案例。
- [Guillermo Rauch（CEO @ Vercel）](https://x.com/rauchg/status/2118166970273292299)：Vercel CEO Guillermo Rauch 预言：未来几周、几个月人们会发现，大多数人类写的软件其实很慢、漏洞多、规格不清且不正确；AI 会把它全部重写很多遍——更快、更便宜、更安全，还会做形式化验证、负载测试与加固。他称这是「软件工程真正的诞生」。对 builder，这是把重构与安全做成产品的长期论据。
- [Guillermo Rauch（CEO @ Vercel）](https://x.com/rauchg/status/2118152230260092940)：Rauch 公布 Vercel Security Reviews 上线 24 小时的数据：识别 6,817 个漏洞，其中 580 个严重或高危，1,441 个已由 agent 直接修复；该服务在 11 月 10 日前完全免费。这是安全 agent 规模化跑起来的首批公开数字，值得做开发者工具的人对照自己的审计覆盖率。
- [Ryo Lu（设计师，前 Cursor、Notion、Stripe）](https://x.com/ryolu_/status/2118207967728451760)：Ryo Lu 在上海 aiDotEngineer 大会上演讲，追问一个问题：当我们能造出任何东西时，还知道自己想要什么吗？他想要的工具是帮人找到自己的答案，而不是跳过形成答案的过程——不只是更多产出，而是更多思考、关心与共同创造的空间。这是 AI 时代产品哲学的一次提醒。
- [Garry Tan（President & CEO @ Y Combinator）](https://x.com/garrytan/status/2118221083233206736)：Y Combinator CEO Garry Tan 实测：GStack 的 /review skill 确实能有效防止 bug。他没展开细节，但来自 YC 掌门人的一句肯定，对做 agent 代码审查工具的人是个有用的信号：把 review 做成可调用的 skill，正在成为 agent 工作流里的标准件。
- [Matt Turck（VC @ FirstMark Capital）](https://x.com/mattturck/status/2118010883754299884)：FirstMark 的 Matt Turck 谈 Dialpad 与 Ada 的结合：他想要的是一个中央大脑（AI），无论文字还是语音、买东西还是要支持，都能 24/7 即时响应、心情永远在线并真正采取行动。两家合并正在追逐这个愿景，他自 Series A 起就是投资人。对 builder：电话与客服 agent 的整合正在加速。
- [Peter Steinberger（OpenClaw，OpenAI）](https://x.com/steipete/status/2118116514700386439)：Peter Steinberger 提问：当 agent 能力不断增强，代表你的项目持续运行、循环演进代码库时，个人用量上限还有意义吗？人类的工作正在变成「策展自动化」。这点出了 agent 时代产品设计的张力：按人头计费的旧模型，正在被常驻 agent 的新形态挑战。
- [Peter Yang（Behind the Craft）](https://x.com/petergyang/status/2118033608007139638)：Peter Yang 说自己不用 AI 打电话给本地小商家，但对用 AI 打给 Xfinity 客服「毫无同情」：对方电话系统在地址有断网故障时竟不让转人工。他这番话点出了电话 agent 的现实切口——先替人啃最难打通的客服电话，再谈礼貌边界。
