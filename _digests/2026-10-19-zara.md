**X 观点**

- [Aaron Levie（Box CEO）](https://x.com/levie/status/2112051081014649303)：agent swarms 让 compute 直接变成产出变量——研究、数据处理、测试等只受时间限制的工作可以被并行化，网络安全、生命/材料科学、交易、QA 在模型足够强时都成 compute-constrained 问题，竞争格局随之改变。
- [Swyx（Latent Space）](https://x.com/swyx/status/2112073533794971941)：Data engineers > AI engineers，懂 Data Intensive Applications 的人与只会 RAG 拼装者的差距空前，市场需求创其职业生涯新高，正公开招人。
- [Thibault Sottiaux（OpenAI）](https://x.com/thsottiaux/status/2112034063934742720)：已与 OpenCode 合作恢复受攻击影响的 API 用户并退还被耗 credits；防御方可提前申请 Daybreak Blue，别等出事。
- [Peter Yang](https://x.com/petergyang/status/2111970651326267529)：主张用 work trials 取代面试——给真实 feature、两周期限、直接交付判断。
- [Thariq（Anthropic）](https://x.com/trq212/status/2111945336537420259)：他更爱 vibe code 游戏而非玩游戏，设想开源游戏加玩家自创角色的新 hook。
- [Guillermo Rauch（Vercel）](https://x.com/rauchg/status/2111929486661018081)：在 AI Gateway 用 deepseek-v4.1-flash 给小游戏加一串改进只花约 30 美分。
- [Garry Tan（YC）](https://x.com/garrytan/status/2111971992769565177)：预言一年左右后大家都会在 agent 工作流里用 AsideAI。

**官方博客**

- [How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)：靠 containment 封顶 blast radius 而非只监督行为——用户批准约 93% 权限弹窗使监督失效；三层防御与三产品隔离形态（claude.ai 临时容器、Claude Code sandbox 使弹窗减 84%、Cowork 完整 VM）；并披露 trust dialog 前解析漏洞、钓鱼 prompt 25 次中 24 次外泄 AWS 凭据、经白名单域名 api.anthropic.com 的外泄事件及修复。
- [An update on recent Claude Code quality reports](https://www.anthropic.com/engineering/april-23-postmortem)：三个独立改动导致的质量问题复盘，4 月 20 日已全部修复；feed 重新列出这篇 4 月旧帖，非新公告。

**播客**

- [No Priors：Beam — Misha Laskin（ReflectionAI）](https://www.youtube.com/@NoPriorsPodcast)：开放有利安全——去掉攻击能力也会去掉防御能力，闭源实验室覆盖不了长尾；首个开放模型 Beam 发布，团队一年从约 30 人扩到约 300 人。
