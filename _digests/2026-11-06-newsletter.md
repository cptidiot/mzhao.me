  - title: "Elena's Growth Scoop"
    role: "Elena Verna"
    summary: "核心论点：几十年来产品团队的核心工作是让用户发现并使用新功能，但成功率极低——核心功能之外的新功能采用率约 0.1%；AI 正在让“功能发现”本身变得不必要，用户只需说出目标，AI 决定调用哪些功能。框架是：传统模式要求用户依次完成“知道功能存在、理解相关性、找到入口、学会操作”，每步都是流失点；AI 时代“谁在操作软件”变了——从人操作软件，变成软件自己操作自己（经 API 与 MCP 与其他产品互联，甚至无需打开底层软件）。她的亲身案例：在 Lovable 工作后几乎不再操心功能采用，只偶尔因 agent 不知道某个功能而发火；功能本身没变，变的是“谁决定使用它”。新问题是信任与授权：用户不必理解每一步，但必须信任过程与结果——如何传达 AI 做了什么决定、为什么、何时需要人工干预、如何可逆；增长的新杠杆从“让人多用产品”变成“让人放心把越来越重要的工作交给软件”，先完成一个小任务建立信任，再逐步委托整个流程，参与度指标可能下降、但客户价值反而上升。但仍有发现问题：AI 解决的是功能发现，不是“用例发现”——极简的提示框不告诉用户能做什么，界面线索被拿掉后，用户反而不知道产品能干什么。结论：把 AI 当作又一个带闪光图标的功能是走反了——AI 不是功能，AI 就是产品；增长团队应停止用提示气泡骚扰用户，转而帮用户拿到第一个有意义的结果、理解还能做什么、建立持续委托的信心。"
