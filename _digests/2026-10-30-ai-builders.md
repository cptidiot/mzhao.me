**X 观点**

- [Swyx（Latent Space）](https://x.com/swyx/status/2115993441004036131)：兴奋于 Cloudflare 以前沿实验室身份出道。他把这视作网络基础设施玩家正式入局前沿模型竞争，值得看 Cloudflare 如何把其全球网络优势转化成模型能力。
- [Josh Woodward（VP @ Google）](https://x.com/joshwoodward/status/2115953461108023400)：NotebookLM 刚解锁了全球主要出版社的 700 多本教科书，全部免费可用。这是 Gemini“专家智能”计划的一部分，学习工具正在从笔记助手变成随身教材库。
- [Thibault Sottiaux（Codex & ChatGPT @ OpenAI）](https://x.com/thsottiaux/status/2115850175868727621)：第 25 天分享：即日起 Pro 100/200/500 各档与 Business Premium 的用量上限全部翻倍；此前说的 Pro 200 降限额也不执行了，Work、Codex 与 dot 的用量继续分开计算。对重度用户这是直接的利好修正。
- [Thariq（前 Claude Code @ Anthropic）](https://x.com/trq212/status/2115937378674372783)：提醒一种 coding agent 狂热：感觉一直在干活、产出很多，实际上什么都没真正推进。他认为这常常是对生活中别的事的逃避——用 agent 的忙碌感代替真正的进展，值得自查。
- [Amjad Masad（CEO @ Replit）](https://x.com/amasad/status/2115890577430438063)：Replit 新能力：粘贴任意 GitHub 仓库链接就能直接跑起来，由它负责环境配置。把“从仓库到可运行应用”的摩擦再压低一步，对快速试项目的人很实用。
- [Guillermo Rauch（CEO @ Vercel）](https://x.com/rauchg/status/2115941392698798365)：称赞团队快速跟进 Node.js 最新 LTS 与安全升级；fetch 默认走 HTTP/2 会带来性能提升，而 agent 会产生大量网络流量，这项升级正好对上 agent 时代的需求。
- [Guillermo Rauch（CEO @ Vercel）](https://x.com/rauchg/status/2115874115118834153)：软件工程的未来是 agent 与 agent 对话，甚至跨公司；Vercel 每天都在从 agent 的反馈里学习如何把产品做得更好，并呼吁在 AGENTS.md 里写上“遇到可改进处就给 Vercel 反馈”。
- [Aaron Levie（CEO @ Box）](https://x.com/levie/status/2116029912243184006)：在前沿用 AI 的人和其他人之间的距离大得难以想象，而且不是在收敛、而是越拉越大：AI 进步曲线近乎垂直，三个月前定好的流程现在可能已经落后；组织变革的速度跟不上，就会被持续甩开。
- [Garry Tan（President & CEO @ Y Combinator）](https://x.com/garrytan/status/2115988128452555092)：试用了 Particle-1 后印象深刻；他还提到 Particle-1 配上最易上手的 agent 群 harness Capy 是“性价比最高的组合”。结合此前 Vercel 接入 Particle 的消息，这个新模型正在开发者圈子里快速起量。
- [Garry Tan（President & CEO @ Y Combinator）](https://x.com/garrytan/status/2115922231910084638)：GBrain 托管版上线：把任何 agent（Claude Code、Codex、Muse、Grok Bot、OpenClaw 等）指向它，就能立刻用上带 pgvector 自动扩缩的 Postgres 记忆层，省去自己搭向量库的麻烦。
- [Claude（Claude 官方）](https://x.com/claudeai/status/2115859390075113836)：iPhone 与 iPad 即将上线下拉搜索：从结果里直接找过去的对话、项目、设置或执行操作，移动端找东西不再需要一层层翻。
- [Claude（Claude 官方）](https://x.com/claudeai/status/2115859388191912193)：iPhone 语音模式现已支持 Apple CarPlay，开车时也能用语音和 Claude 对话，驾驶场景的免手操作补上了一块。

**播客**

- [State of AI 2026: The Biggest Stories of the Year (and AGI in 2027?) — Nathan Benaich（The MAD Podcast with Matt Turck）](https://www.youtube.com/@DataDrivenNYC/videos)：年度《State of AI》报告作者 Benaich 预测 AGI 可能在 2027 年到来，依据是能力每周都在跃升、模型在法律金融等知识工作上已接近超过人力；核心驱动是递归自我改进——Claude 已主导 Anthropic 8 月 26% 的模型研发（数月前仅 1%）；他同时认为网络攻击风险比 AI 灭绝更真实，数据中心反弹、追赶 OpenAI 需万亿美元量级、欧洲受制于 8 万 GPU 与电价，都是今年的关键叙事。
