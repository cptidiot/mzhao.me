# AI Builders Digest — 2026-11-18

## X 观点

**Matt Turck（VC @ FirstMark Capital）**：宣布投资持续学习公司 Remanence Labs，与 EQT 共同领投 3000 万美元种子轮，押注“让智能随时间复利增长”。持续学习是 agent 基础设施的下一个赌注，值得关注其技术路线。[X 原帖](https://x.com/mattturck/status/2122717441461739571)

**Matt Turck（VC @ FirstMark Capital）**：Daytona 继续推 agentic 基建创新：首家提供 macOS 沙箱，服务电脑使用 agent 以及 Apple 应用的构建与测试。Mac 端 agent 开发终于有了原生沙箱可用。[X 原帖](https://x.com/mattturck/status/2122726760185741673)

**Josh Woodward（VP @ Google Labs）**：Gemini 现在能在美、日、韩、加、澳、印六国免费替用户办事，跑在新的 Gemini 4 Hydrogen 模型上。美国先上打电话给本地商家、Google Pay 结账、RCS 短信、Gmail 转发、密码管理器登录等功能，Workspace 集成也大幅升级，邮件、文档、表格与日历都能在 Gemini 里直接操作。[X 原帖](https://x.com/joshwoodward/status/2122737427970425171)

**Swyx（Latent Space 主持人）**：Devin Bots 是多智能体团队的正确形态：常驻、主动、按 ROI 调校，对结果而非任务负责，能带 subagent 团队并自我复核，通过电话、短信、Slack 随处可用，以交互式 artifact 而非长聊天汇报。关键转变是每个 bot 有持久身份与记忆，他已把 AEO、QA、跨平台移植、个人行政与视频剪辑交了出去。他的结论是：不要幻想“AI 员工”，要的是对结果负责的 agent 管理者。[X 原帖](https://x.com/swyx/status/2122746401482592549)

**Sam Altman（CEO @ OpenAI）**：6.2 Sol 与 Astra 正式发布：两个模型都非常聪明且 token 效率极高，尤其 6.2 Sol ultrafast 值得一试。他也坦承新模型在“好用程度”上还有工作要做，会是后续版本的优先项。能力与易用性之间的取舍，是这次发布的基调。[X 原帖](https://x.com/sama/status/2122798039899263456)

**Amjad Masad（CEO @ Replit）**：Agent swarm 是 AI 扩展的下一个前沿：过去靠训更大模型、给更多思考时间，现在可以并行跑很多 agent、探索不同方法、互相挑战，OpenAI 已用这招在数学上取得突破。Replit 现在起一句话就能拉起一个 swarm，不用自己搭编排基建，集体机器智能从此人人可编程。[X 原帖](https://x.com/amasad/status/2122809964649459861)

**Guillermo Rauch（CEO @ Vercel）**：OpenAI 刚发布了全球网络安全能力最强的模型，时机很关键；并透露 Vercel 的 DeepsecBench 是个隐形网络安全基准，没有任何实验室能提前拿到代码库训练。基准可信度是亮点，值得做安全评估的 builders 留意。[X 原帖](https://x.com/rauchg/status/2122812237169426606)

**Guillermo Rauch（CEO @ Vercel）**：agent-browser vitals 是件大事：浏览器自己做性能优化，自我优化的软件来了。对做 web 性能与 agent 浏览的 builders，这是一个值得跟进的信号。[X 原帖](https://x.com/rauchg/status/2122830064152899991)

**Nikunj Kothari（投资人 @ FPV Ventures）**：X 上模型口碑像过山车：过去几个月 OpenAI 占上风，现在 Anthropic 5.5 与 Gemini Carbon 拿走赞誉，轮到 Grok 惊艳全场了。模型竞争的舆论周期越来越短， builders 做选型不必追着口碑跑。[X 原帖](https://x.com/nikunj/status/2122833396787495317)

**Peter Yang（AI 技能与教程博主）**：除 Opus 5.5 等少数特例，模型基本是保质期最短的软件，过几周大家就移情别恋；没必要为此动感情，更重要的是让自己的技能在任何新模型上都好用。模型会换，跨模型的工作流才是资产。[X 原帖](https://x.com/petergyang/status/2122839368444661870)

**Dan Shipper（CEO @ Every）**：Every 团队给出 Astra 与 Sol 6.2 的完整评分，称很难想起上一次有这种量级的前沿模型发布，最接近的参照是 Opus 5。评分表本身值得 builders 对照自己的使用场景看。[X 原帖](https://x.com/danshipper/status/2122858139989012510)

**Swyx（Latent Space 主持人）**：Astra 模型本身是扎实的小版本升级：效率是当前 RL 三大目标之一，OpenAI 在这方面世界领先；他日常用 Astra 做工作流自动化，不再卡进死循环，还跑了 Latent Space 与 aiDotEngineer 的内容发布管线。他对发布的主要批评集中在那支 6.2 Astra 广告——居然没人提前否决。[X 原帖](https://x.com/swyx/status/2122862646265520150)

**Thibault Sottiaux（Codex & ChatGPT @ OpenAI）**：6.2 Sol ultrafast 速度感完全不同，Pro 200/500 用户值得一试；并解释了网红与大众评价温差的原因：提前给少数人试用后、近 3–4 天又改了很多，没人重新测试，视频是上周做的。模型比前代是大幅跃升，但“品味与好用度”仍有提升空间，团队已在听反馈。[X 原帖](https://x.com/thsottiaux/status/2122929829863735594)

## 播客

**Latent Space × Black Forest Labs（播客）**：对话 latent diffusion 联合发明人 Andreas Blattmann 与 SDXL、Flux 操刀者 Dustin Podell：BFL 从图像生成走向“视觉智能”——视频建模是理解世界如何运作的核心手段，Flux.3 Action 是 70 亿参数机器人模型，目标是给机器人演示一次动作它就能学会；Flux Context 则瞄准日常图片编辑，替代 Canva 与 Photoshop 的常规操作。公司累计融资 4.5 亿美元，去年 12 月公布的 1 亿美元年收入已被超越。[节目页](https://www.youtube.com/watch?v=8cGfJOU3AlQ)
